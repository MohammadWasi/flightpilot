# Getting help

Start with the [README](README.md), [user guide](docs/user-guide.md), [agent installation guide](docs/agent-installation.md), and [known limitations](docs/limitations.md). For local setup diagnostics, run `pnpm run doctor` and review its output privately before sharing any part of it.

- **Reproducible bugs:** open a [bug report](https://github.com/MohammadWasi/flightpilot/issues/new?template=bug_report.yml) with your operating system, Node/pnpm versions, commit, and steps using fictional data.
- **Ideas and improvements:** open a [feature request](https://github.com/MohammadWasi/flightpilot/issues/new?template=feature_request.yml) explaining the problem and expected outcome.
- **Setup questions:** search existing issues, then open a [help request](https://github.com/MohammadWasi/flightpilot/issues/new?template=help.yml) with the relevant redacted error.
- **Security vulnerabilities:** follow the private [security reporting process](SECURITY.md).
- **Community conduct:** follow the private [Code of Conduct reporting process](CODE_OF_CONDUCT.md).

Issues are public. Do not include real traveller names, dates of birth, passport or card details, booking references, database files, access tokens, encryption keys, or `.env` contents. Use fictional records and inspect screenshots for private information.

This is a community project maintained by [@MohammadWasi](https://github.com/MohammadWasi), with no guaranteed support response time. It is not an airline, travel agency, or supplier support channel. Questions about a provider account or a real-world reservation belong with the provider or airline. The default FlightPilot workflow produces synthetic bookings; Duffel mode uses that provider's test environment.
